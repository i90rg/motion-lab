CSS-анимации

С помощью правила @keyframes можно делать сложные и бесконечные анимации без JavaScript.

Что такое @keyframes

В отличие от перехода, анимация на @keyframes может состоять из многих шагов (ключевых кадров), повторяться бесконечно и запускаться сама, без наведения мыши.

Сначала анимацию описывают через @keyframes и дают ей имя, а потом подключают к элементу свойством animation.

Синтаксис

@keyframes pulse {
  0% {
    transform: scale(1);
  }
  50% {
    transform: scale(1.3);
  }
  100% {
    transform: scale(1);
  }
}

.circle {
  animation: pulse 1.5s ease-in-out infinite;
}

Свойства animation

  • animation-name — имя анимации из @keyframes;
  • animation-duration — длительность одного повтора;
  • animation-timing-function — функция плавности;
  • animation-delay — задержка;
  • animation-iteration-count — сколько раз повторить (infinite — бесконечно);
  • animation-direction — направление (alternate — туда и обратно);
  • animation-fill-mode — какие стили оставить после окончания;
  • animation-play-state — пауза или воспроизведение.

animation-fill-mode

Это свойство часто вызывает вопросы. Оно отвечает за то, как выглядит элемент до начала и после конца анимации:

  • none — после анимации элемент возвращается к обычным стилям;
  • forwards — остаётся в последнем кадре;
  • backwards — во время задержки уже принимает стили первого кадра;
  • both — сразу оба варианта.

Например, для плавного появления блока при загрузке страницы обычно пишут animation: fade-in 0.5s ease-out both;.
