# MOTION LAB - Анимации и переходы в веб-разработке

**Сайт:** https://i90rg.github.io/motion-lab/

## О проекте

MOTION LAB - это образовательный веб-ресурс, посвящённый анимациям и переходам на веб-страницах. На сайте собраны основные способы «оживить» интерфейс: от простых CSS-переходов до библиотеки GSAP. Проект создан, чтобы помочь начинающим веб-разработчикам разобраться, какой способ анимации выбрать для своей задачи и как сделать так, чтобы сайт не тормозил.

## Основные возможности

### CSS-анимации

* **CSS transitions** - плавное изменение стилей между двумя состояниями
* **@keyframes** - многошаговые и бесконечные анимации без JavaScript
* **Функции плавности** - ease, linear, ease-in, ease-out, cubic-bezier

### Анимации на JavaScript

* **requestAnimationFrame** - покадровая анимация, синхронизированная с экраном
* **Web Animations API** - управление анимацией из JS (запуск, пауза)
* **IntersectionObserver** - запуск анимации при появлении блока на экране

### Библиотека GSAP

* Методы `gsap.to`, `gsap.from`, `gsap.fromTo`
* Таймлайны - последовательности анимаций с управлением
* ScrollTrigger - анимации при прокрутке страницы
* Видеоурок по GSAP

### Сравнение и производительность

* Сравнительная таблица CSS transition, @keyframes, Web Animations API и GSAP
* Советы по производительности (transform и opacity, 60 FPS)
* Учёт настройки `prefers-reduced-motion`
* Рекомендации по выбору способа анимации для разных задач

## Технологический стек

### Frontend

* **HTML5** - семантическая разметка
* **CSS3** - стилизация и анимации (методология БЭМ)
* **Semantic UI 2.5.0** - CSS-фреймворк
* **JavaScript** - интерактивные элементы
* **jQuery 3.7.1** - упрощение работы с DOM
* **GSAP 3.12.5 + ScrollTrigger** - анимации на сайте

### Features

* Адаптивный дизайн (Mobile-first): телефоны, планшеты (от 768px), десктопы (от 992px)
* Бургер-меню на мобильных устройствах
* Интерактивные демо анимаций на страницах
* Таблицы сравнения
* Формы обратной связи и подписки с проверкой полей
* Галерея с фильтром и модальным окном
* Адаптивные изображения (WebP + JPEG, `srcset`, `sizes`)
* Примеры кода
* Видео-контент интеграция (RuTube)

## Запуск

Сайт статический, сборка не нужна. Библиотеки подключаются через CDN, поэтому нужен интернет.

```bash
git clone https://github.com/i90rg/motion-lab.git
cd motion-lab
python -m http.server 8080
```

После этого открыть http://localhost:8080 (или просто открыть `index.html` в браузере).
