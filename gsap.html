Библиотека GSAP

GSAP — одна из самых популярных JavaScript-библиотек для анимации.

Что такое GSAP

GSAP (GreenSock Animation Platform) позволяет анимировать почти что угодно: CSS-свойства, SVG, объекты на Canvas. Главные плюсы — простой синтаксис, одинаковая работа во всех браузерах и удобные таймлайны.

Сейчас GSAP и все его плагины бесплатные. На этом сайте GSAP используется для появления блоков при прокрутке.

Подключение

Проще всего подключить библиотеку через CDN:

<script src="https://cdnjs.cloudflare.com/ajax/libs/gsap/3.12.5/gsap.min.js"></script>
<script src="https://cdnjs.cloudflare.com/ajax/libs/gsap/3.12.5/ScrollTrigger.min.js"></script>

Также можно установить через npm: npm install gsap.

Основные методы

// из текущего состояния в новое
gsap.to('.box', { x: 200, rotation: 360, duration: 1 });

// из указанного состояния в текущее
gsap.from('.title', { y: -50, opacity: 0, duration: 1 });

// из одного состояния в другое
gsap.fromTo('.circle', { scale: 0 }, { scale: 1, duration: 0.5 });

Таймлайн

Таймлайн позволяет выстроить несколько анимаций друг за другом и управлять ими вместе: запускать, ставить на паузу, проигрывать назад.

const tl = gsap.timeline({ paused: true });

tl.to('.item-1', { y: -40, rotation: 180, duration: 0.5 })
  .to('.item-2', { scale: 1.5, duration: 0.5 })
  .to('.item-3', { x: -30, borderRadius: '50%', duration: 0.5 });

ScrollTrigger

ScrollTrigger — плагин GSAP, который запускает анимацию при прокрутке страницы. Именно так на этом сайте появляются разделы.

gsap.registerPlugin(ScrollTrigger);

gsap.from('.section', {
  y: 40,
  opacity: 0,
  scrollTrigger: {
    trigger: '.section',
    start: 'top 85%'
  }
});
