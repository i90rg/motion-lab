Анимации на JavaScript

Когда возможностей CSS не хватает, анимацией можно управлять из JavaScript.

Зачем нужен JavaScript

CSS хорошо подходит для простых эффектов. Но иногда нужно:

  • поставить анимацию на паузу или запустить её назад;
  • менять анимацию в зависимости от действий пользователя (движение мыши, прокрутка);
  • анимировать то, что не является CSS-свойством, например рисунок на Canvas.

requestAnimationFrame

Метод requestAnimationFrame вызывает функцию перед каждой перерисовкой экрана (обычно 60 раз в секунду). Это лучше, чем setInterval, потому что анимация синхронизирована с экраном и останавливается, когда вкладка неактивна.

const box = document.querySelector('.box');
let x = 0;

function move() {
  x += 2;
  box.style.transform = `translateX(${x}px)`;
  if (x < 300) {
    requestAnimationFrame(move);
  }
}

requestAnimationFrame(move);

Web Animations API

Web Animations API — встроенный в браузер способ запускать анимации из JavaScript. Метод element.animate() принимает ключевые кадры и настройки, а возвращает объект, у которого есть методы play(), pause(), reverse().

const animation = square.animate([
  { transform: 'translateX(-100px) rotate(0deg)' },
  { transform: 'translateX(100px) rotate(360deg)' }
], {
  duration: 1500,
  iterations: Infinity,
  direction: 'alternate'
});

animation.pause();

IntersectionObserver

Часто нужно запустить анимацию, когда блок появляется на экране при прокрутке. Для этого есть IntersectionObserver — он сообщает, когда элемент попал в видимую область. Это удобнее и быстрее, чем обрабатывать событие scroll.

const observer = new IntersectionObserver((entries) => {
  entries.forEach((entry) => {
    if (entry.isIntersecting) {
      entry.target.classList.add('visible');
    }
  });
});

document.querySelectorAll('.card').forEach((card) => observer.observe(card));
