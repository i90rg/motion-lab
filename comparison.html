Производительность

Чтобы анимация была плавной, браузер должен успевать рисовать 60 кадров в секунду, то есть примерно один кадр за 16 мс. Несколько советов:

  • анимировать transform и opacity — браузеру не нужно пересчитывать расположение элементов;
  • не анимировать width, height, top, left, margin;
  • не злоупотреблять свойством will-change;
  • проверять анимацию во вкладке Performance в инструментах разработчика.

Также некоторым людям движение на экране мешает. Для них в системе есть настройка «уменьшить движение», и её можно учесть в CSS:

@media (prefers-reduced-motion: reduce) {
  * {
    animation: none !important;
    transition: none !important;
  }
}

Что выбрать

CSS transition

Для простых эффектов: наведение на кнопки и ссылки, открытие меню, смена цвета.

CSS @keyframes

Для повторяющихся анимаций: загрузчики, пульсация, появление элементов при загрузке страницы.

Web Animations API

Когда нужно управлять анимацией из JavaScript, но не хочется подключать библиотеку.

GSAP

Для сложных анимаций из многих шагов, анимаций при прокрутке и работы с SVG.
